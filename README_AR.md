# CRAVA V9 — المتجر الكامل

هذه النسخة تحتوي على:

- بوكسات CRAVA S / M / L / XL.
- اختيار نكهة كل كوكي وكل Twist Roll بشكل منفصل.
- Orbs مضافة تلقائيًا داخل كل بوكس.
- تسجيل الدخول مطلوب لإنشاء الطلب، بدون اشتراط OTP حاليًا.
- الدفع عند الاستلام فقط.
- التوصيل داخل عمّان فقط، برسوم 2 أو 3 د.أ حسب المنطقة.
- نقاط قابلة للخصم: 100 نقطة = 1 د.أ، والحد الأقصى 100 نقطة لكل طلب.
- XP منفصل عن النقاط ولا يتم صرفه.
- كود دعوة اختياري في صفحة الدفع، ومكافأة 100 XP لصاحب الكود بعد تسليم الطلب فقط ولمرة واحدة.
- تقييم واحد للبوكس وتقييم منفصل للتوصيل بعد حالة `delivered` فقط.
- لوحة إدارة كاملة للطلبات، الأسعار، التقييمات، العملاء، النقاط، والبوكسات المرقّمة.

## الملفات الأساسية

- `index.html` — واجهة المتجر.
- `vault-7f3c9a.html` — لوحة الإدارة.
- `supabase_setup_v9.sql` — قاعدة البيانات والدوال والسياسات.
- `config.js` — رابط Supabase والمفتاح العام.

## التثبيت أو التحديث

1. خذ نسخة احتياطية من قاعدة البيانات الحالية.
2. افتح Supabase > SQL Editor > New Query.
3. انسخ ملف `supabase_setup_v9.sql` كاملًا واضغط Run مرة واحدة.
4. أنشئ حساب الإدارة من الموقع.
5. نفّذ الأمر الموجود في آخر ملف SQL بعد استبدال البريد ببريد الإدارة:

```sql
update public.profiles set is_admin=true
where id=(select id from auth.users where email='YOUR_ADMIN_EMAIL@example.com');
```

6. افتح لوحة الإدارة من:

```text
vault-7f3c9a.html
```

7. راجع أسعار البوكسات من تبويب **أحجام البوكس** قبل الإطلاق.

## الأسعار المبدئية القابلة للتعديل

- CRAVA S: 6 د.أ
- CRAVA M: 8 د.أ
- CRAVA L: 10 د.أ
- CRAVA XL: 12 د.أ

يمكن تغييرها فورًا من لوحة الإدارة بدون تعديل الكود.

## النشر

ارفع محتويات المجلد إلى GitHub ثم انشرها على Vercel. لا ترفع مفاتيح `service_role` داخل أي ملف؛ الموقع يستخدم المفتاح العام فقط، والحماية الفعلية تعتمد على RLS ودوال Supabase.
